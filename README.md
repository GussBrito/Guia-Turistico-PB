# Guia Turístico da Paraíba

## Descrição
Este projeto é um **Guia Turístico** interativo que apresenta locais turísticos da Paraíba. Desenvolvido por **Gustavo Brito**, o site permite aos usuários explorar informações sobre diversos locais, visualizar imagens e adicionar, editar ou excluir novos destinos turísticos.

A aplicação foi construída utilizando as tecnologias:

- **HTML**: Estrutura básica do site.
- **CSS**: Estilos e design responsivo.
- **JavaScript**: Funcionalidades dinâmicas para adicionar, editar e excluir locais turísticos.

## Funcionalidades
- Exibição de uma lista de locais turísticos com título, descrição e imagem.
- Modal para adicionar e editar locais turísticos.
- Exclusão de locais com confirmação de exclusão.
- Interface responsiva para melhor visualização em dispositivos móveis.

## Tecnologias Utilizadas
- **HTML5**
- **CSS3**
- **JavaScript**
- **JSON Server** (opcional, para simular uma API local)

## Como Usar
1. Clone este repositório:
    ```bash
    https://github.com/GussBrito/Roteiro-6-LSW-.git
    ```
2. Abra o arquivo `index.html` em seu navegador para visualizar o site.
3. Para executar a aplicação localmente e testar a API, você pode utilizar o **JSON Server**:
    ```bash
    npm install -g json-server
    json-server --watch db.json --port 3000
    ```
4. O site estará disponível em `http://localhost:3000`.
